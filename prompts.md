# Style prompts

Fill the [BRACKETS], then run the style's skill (or paste the prompt and ask for "script + voice-over with emotion
tags + scene list with timings").

1. **Documentary**: Make a 35-second vertical documentary reel about [TOPIC]. Cinematic footage, a film-title card
   with a runtime bar, a calm narrator voice, slow push-ins, warm colour grade, word-by-word captions.
2. **Podcast**: Make a 35-second vertical podcast reel where two characters argue about [QUESTION]. Studio desk,
   ON AIR sign, mics, name plates, chat bubbles for each point, a different voice for each host, the winner revealed
   at the end.
3. **Courtroom**: Make a 35-second vertical courtroom reel that puts [IDEA] on trial. A judge, one character for and
   one against, 12 jurors voting guilty or not guilty in secret, gavel sound, the verdict and one fix as the ending.
4. **Poster styles**: Make a 35-second vertical reel showing one brief, [BRIEF], as 20 poster styles. A numbered
   list on the left, each poster flipping in on the beat, style name in big type, a save-this ending.
5. **Desk explainer**: Make a 35-second vertical list reel: [NUMBER] [THINGS] for [AUDIENCE]. A character at a desk,
   one card per item with a number badge and a live mini demo, cream background, terracotta captions, dark end card.
6. **Cartoon**: Make a 35-second vertical cartoon reel that explains [CONCEPT] with a little mascot. Bold flat
   colours, a big number or meter as the hook, the mascot reacting to each step, punchy sound effects.
7. **Terminal**: Make a 35-second vertical terminal reel about [TOPIC]. A dark code window typing commands, each
   result as a card with old price struck through and new price counting down, a running total, the final saving
   in big green type.
8. **Night desk**: Make a 35-second vertical story reel: a character at a night desk with rain on the window and a
   lamp. They hit a problem, a helper appears with the fix, step cards pop in on each line, ending with a
   comment-keyword pill.
